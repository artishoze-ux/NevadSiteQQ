# Nevad — концепт сайта загрузки

Демонстрационный одностраничный сайт вымышленной продуктовой линейки **Nevad Labs**: языковая модель **Nevad 3** и десктопный ИИ-агент **Nevad Agent**.

Оформление следует `DESIGN.md`: светлый холст, авроральная дымка, Inter + Newsreader + JetBrains Mono, тонкие линии, угольно-чёрные CTA, максимум 1244px, крупные вертикальные отступы, минимум теней.

## Запуск

Любой статический сервер из папки проекта:

```powershell
python -m http.server 8123 --bind 127.0.0.1
```

Затем открыть `http://127.0.0.1:8123/`.

Можно открыть и просто `index.html` двойным кликом — скрипты работают с локального диска, без сборки и зависимостей.

## Структура

```text
index.html   разметка страницы, окно продукта, диалог загрузки
styles.css   токены дизайн-системы, компоненты, адаптив
app.js       выбор ОС, имитация загрузки, копирование, анимации
DESIGN.md    исходное визуальное ТЗ / референс стиля
```

## Возможности

- Автоопределение ОС с ручным переключением macOS / Windows / Linux
- Живое окно продукта с вкладками «Активность», «Сессия», «Находки»
- Модальное окно загрузки с прогрессом и контрольной суммой
- Копирование SHA-256, ссылок и CLI-команды
- Раскрытие текста манифеста по скроллу и плавные появления секций
- Мобильное меню, горячая клавиша `D` — переход к загрузкам

## Важно

Все продукты, метрики, отзывы, сборки и контрольные суммы вымышлены. Кнопки загрузки **не скачивают файлы** — это симуляция с честной пометкой в диалоге и подвале. Сайт создан как концепт-макет.
